# Z Monitor 隐私政策

- 更新日期：2026 年 11 月 8 日
- 生效日期：2026 年 11 月 8 日
- 适用应用：Z Monitor VZ1.1.0（HarmonyOS 手机版）

请在使用本应用前阅读本政策，了解我们处理哪些信息、为什么处理这些信息，以及你可以如何管理这些信息。

**当前 VZ1.1.0 通过相机 Wi-Fi 和蓝牙提供相机连接、监看及拍摄控制。相机画面、照片和连接记录不会由本应用自动上传至我们运营的服务器。华为账号登录、身份验证公钥请求、头像加载、公开政策网页及你主动发送的邮件涉及相应网络服务。**

你可以不登录，使用基础连接和控制、已有本机照片回看等功能。相机相册、原片传输、新增拍照预览保存及其他普通用户功能需要有效登录；具体见第九节。头像、昵称授权可自行选择，拒绝这些资料授权不影响基本身份登录。

本政策仅适用于上述版本，不自动替代其他版本的隐私政策，也不追溯扩大此前取得的授权。你通过应用访问外部网站、使用邮件服务，或使用系统提供的网络、文件管理和云备份服务时，相应服务提供者也会按照其自身的规则处理信息。

## 二、我们处理的信息及用途

我们按照功能需要处理下列信息。实际可获得的字段取决于手机系统、华为账号服务和相机返回的内容。

| 信息类别 | 具体内容 | 用途及处理方式 |
| --- | --- | --- |
| 网络与 Wi-Fi 连接信息 | 网络名称、BSSID、信号、加密类型、连接状态、系统配置编号及相机局域网地址 | 用于发现、连接和核对网络；必要的重连记录在本机保存，具体见下文 |
| 蓝牙连接与相机信息 | 设备名称、引用、信号、型号、版本、能力、可能包含序列号的设备信息、认证及拍摄状态 | 用于发现、核对和遥控所选相机；连接档案和最近连接记录在本机保存 |
| 本机生成的连接标识 | 随机生成的控制端标识和身份 | 用于向相机标识本应用实例和恢复连接，不取自手机硬件序列号 |
| 相机画面、照片及文件信息 | 实时预览、私有预览 JPEG、所选照片及元数据、目录和缩略图 | 用于监看、拍摄辅助、浏览及主动下载，具体见第三节 |

| 华为账号与可选资料 | 身份令牌、校验值、UnionID、可得 OpenID、应用标识、签发与到期时间、资料授权状态，以及授权的昵称和头像地址 | 用于确认身份、恢复登录和展示资料；令牌仅在内存会话中保留，具体见第九节 |
| 隐私选择记录 | 所确认的说明版本及用于识别该说明的公开运营者信息 | 在本机保存，用于记录选择及判断是否需要再次提示；不记录同意时间或 IP 历史 |
| 主动提交的反馈信息 | 发件邮箱、问题描述及你自行附带的图片或其他文件 | 用于回复、排查问题和办理权利请求，具体见第五、六节 |

### 1. 相机 Wi-Fi

为显示可选网络、连接你选择的相机、核对网络变化及重连，应用处理系统返回的网络名称、网络标识（例如 BSSID）、信号、加密类型、连接状态、系统配置编号，以及相机局域网 IP 地址。扫描结果和当前网络核对信息在运行时使用。

你输入的相机 Wi-Fi 密码按连接需要传给系统接口。应用自己的连接历史不保存密码；系统可能保存网络配置，由你在系统设置中管理。应用在私有空间保存用于重连的网络名称、加密类型、配置编号、相机地址及最近连接时间。你可以在应用中删除连接记录，系统已保存的网络配置需另行管理。

### 2. 蓝牙发现、配对与遥控

为发现相机、核对设备身份、配对和执行遥控，应用处理附近设备名称、信号、系统及低功耗蓝牙设备引用、连接状态、相机返回的型号、版本、设备及能力信息、鉴权消息、随机校验值、拍摄状态和用户控制指令。相机返回的设备信息可能包含序列号。首次配对按系统或机身提示由你确认配对码。

应用在本机保存已完整核对相机的连接档案和最近连接快捷记录，两类记录各限最近 3 台相机。记录按用途包含名称、系统及蓝牙引用、连接类型、版本、最近连接时间，以及根据本机控制端身份和相机认证标记计算的校验摘要，用于下次恢复前重新核对。原始相机识别字段、系统配对码和配对密钥不作为该历史档案持久保存。你可删除应用连接记录；系统蓝牙配对关系需在系统设置中分别删除。

基础蓝牙遥控可拍照，有效登录后可开始对焦和录像。你主动切换到相机 Wi-Fi 时，应用请求机身开启 Wi-Fi，释放蓝牙后按系统扫描结果选网；该流程不读取相机保存的 Wi-Fi 密码。

### 3. 本机连接标识与设置

应用生成并在私有空间保存随机的 Wi-Fi 控制端标识和蓝牙控制端身份，用于向所连接相机标识本应用实例、建立会话和后续重连。这些标识不取自手机硬件序列号。删除单条相机历史不会同时删除这些公共连接标识；清除应用数据可清理相应私有记录。

外观、允许的监看布局、方向、左右手、辅助选项，以及下载格式（JPG、NEF 或两者）和相册视图（列表或卡片）等偏好在本机保存，用于恢复你的设置。已保存偏好不会扩大当前登录权限。说明版本记录用于判断是否需要再次展示隐私及协议提示。

## 三、图像、照片与后台处理

### 1. 实时预览和拍摄控制

应用接收所连接相机的预览画面、当前曝光档位、光圈、快门、ISO／自动 ISO、曝光补偿及拍摄、录像状态，并发送你发起的控制请求。有效登录后，按机身支持处理测光、对焦模式、AF 区域、白平衡、K 色温、优化校准、照片格式和质量等参数；辅助分析在手机上使用预览图像计算。应用不利用画面识别人脸身份或建立广告画像。

实时画面随刷新替换；未主动保存的预览不作为照片档案保留。应用控制的录像由相机执行并保存在机身存储卡，本版不提供视频文件下载。

### 2. 本机拍照预览与历史副本

有效登录并启用拍照预览保存后，应用可将拍照提交时有效的预览 JPEG 保存至应用私有空间，并记录保存时间、文件位置、大小、格式和尺寸等索引。预览截图与相机原片分别管理，不代表机身实际曝光、存卡或原片质量，也不会自动写入系统公共相册。

已有本机预览及历史副本可在未登录时回看、缩放和拖动。你可在本机照片页面经二次确认清空全部副本，失败时可重试；本版没有单张删除或应用内分享入口。单张预览上限 8 MiB，私有图片目录配额 1 GiB，索引最多 1000 条，到限停止新增保存，不自动删除已有照片。

### 3. 相机相册和原片下载

有效登录后进入相机相册，应用通过相机 Wi-Fi 按需读取文件标识、名称、格式、大小、时间、尺寸及必要的设备和存储卡身份信息，用于浏览、JPG＋RAW 配对、原名保存和文件校验。浏览时读取当前可见窗口需要的缩略图和所选照片的较大预览，并核对基本目录变化。文件名即使不在界面展示，仍可用于匹配和导出。

你确认下载后，应用接收所选 JPG、RAW／NEF 或同张照片的两种格式，核对文件身份及完整性，并保存到所选接收目录。应用保留相机存储卡中的原文件，采用安全回退名称和重名处理保护已有目标文件。本版不提供删除相机原片的功能。

**照片可能包含人物、版权、相机或镜头信息、设备序列号、拍摄时间，以及相机已经写入的位置信息。**完整原片传输会保留文件已有内容和元数据，即使应用界面不显示这些字段。请在向他人提供照片前自行检查并尊重相关人员的权益。

### 4. 接收目录、队列与可靠保存

你通过系统文件选择器选择接收目录，应用取得本次传图会话的临时访问能力，同次批量保存共用授权。退出传图会话后需重新选择，应用不保存接收目录历史或持久访问授权。系统选择器返回时仍需核对当前登录和操作是否有效。

应用在私有空间保存导出回执、未完成文件清理记录，以及导出名称序号和来源对应关系。记录可能包含来源文件身份、目标目录和文件 URI、文件名、大小、SHA-256 校验值、归属及结果状态，用于防止重复导出、分配名称、核对文件和重试清理。来源身份会用到相机厂商、型号和序列号计算的摘要及照片身份字段；这些摘要仍用于关联来源，不作为已匿名化信息处理。保留文件位置记录不等于保留访问该目录的授权；没有可用授权时，清理可能需要你重新选择目录或在文件管理中处理。

当前下载队列不跨应用重启恢复。退出、到期或身份失效后，不再追加任务或启动后续新文件，包括同张照片尚未开始下载的另一格式。已经创建临时文件并进入接收的当前整张文件，可继续接收剩余分块、校验和导出；下一张文件不再开始。已提交的相机控制事务可进行必要结果核对。你明确取消下载、关闭相册或断开连接时，仍按对应取消和清理流程处理；已完成保存的文件不会因退出登录被自动删除。

### 5. 后台和中断处理

切换到后台或锁屏时，应用会根据当前状态暂停监看，并停止或收尾正在进行的传输。已经发送给相机的指令可能继续执行，离开应用不保证停止机身录像，请以相机实际状态为准。系统接收目录选择期间，应用按相应选择会话处理；选择完成后还会核对当前状态。

| 权限 | 用途 |

## 五、信息保存、保护与清理

### 1. 保存位置和期限

本应用不设用于集中保存用户账号、相机照片或连接历史的开发者云端数据库。应用私有数据保存在你的手机，所选原片保存到你指定的目录。华为账号、网页托管、邮件、系统备份和云盘等服务产生的数据按各自场景和规则处理；GitHub 网页访问数据可能在境外处理，具体见第六节。

| 信息 | 保留及清理规则 |
| --- | --- |
| 实时画面、扫描结果、控制及鉴权临时状态 | 在相应操作和会话中使用；随画面刷新、操作结束、取消、连接关闭或进程结束释放相应数据和引用。 |
| Wi-Fi、蓝牙连接历史 | Wi-Fi 历史保留至你删除或清理应用私有数据，不按固定数量自动淘汰；不保存 Wi-Fi 密码或 BSSID。蓝牙连接档案和最近连接快捷记录各保留最近最多 3 台，较旧记录可被替换，也可主动删除。系统网络配置和蓝牙配对另行管理。 |
| 随机控制端标识、功能偏好及说明版本 | 保存在私有空间，按连接和设置用途使用，保留至设置变更或应用私有数据被清除；系统备份和恢复可能影响实际保留情况。 |
| 已保存的预览、历史本机副本及索引 | 保留至你清空全部副本或清理应用私有数据。达到单张、目录或索引上限后停止新增，不自动删除已有照片。 |
| 照片目录、缩略图及较大预览 | 主要在内存中按需处理。退出相册时清除详情显示，但同一相机的目录和缩略图可在本次应用运行期间继续复用，切换相机或进程结束后释放相应缓存。 |
| 传输临时文件 | 传输完成、取消或关闭相应会话时安排清理。目标目录中的未完成文件须核对归属并具备访问条件后清理；清理失败时保留必要记录供后续重试。 |
| 导出回执和未完成清理记录 | 在本机保存。成功回执最多保留 1000 条，并受状态容量限制，较旧回执可能被替换；替换回执不删除已导出照片。未完成清理记录最多 128 条，保留至处理完成或应用私有数据清理；达到限制时可能无法继续新增传输。 |
| 导出名称序号及来源对应关系 | 为后续文件命名、对应同一来源而在本机保存，来源对应记录最多 2000 条，受数量限制淘汰或随应用私有数据清理而删除。 |
| 完整导出照片 | 保存在你选择的目录，由你在文件管理、云盘等对应位置删除。退出、清空私有预览或卸载应用不代替对这些照片的管理。 |
| 原始身份令牌、本机账号记录及可选资料 | 令牌仅保留于内存会话；安全资产中的恢复记录沿用已验证的有效期，按第九节退出、失效和重试规则清理，不因离线恢复续期。 |
| 反馈邮件及附件 | 保留至反馈或请求处理完成，删除不再必要的信息；法律另有要求或未解决争议确需保留的，在相应必要期限内保留。 |

应用没有运行诊断记录查看或 TXT 导出功能，也不自动向开发者上报运行日志。连接历史、导出回执和清理记录按各自功能保留。系统自身的诊断、缓存、备份及已导出文件由相应系统或服务管理。若应用停止提供服务，我们将停止相应处理，并对我们持有且不再需要的信息依法删除或匿名化；仅在你设备中的副本仍需由你按上述方式管理。

### 2. 保护措施

本机账号记录使用系统安全资产保护，网络身份验证采用 HTTPS 和凭据校验，文件保存采用身份与完整性核对等措施。相机本地通信的安全能力受机身协议、系统和网络环境影响，不保证全部相机链路端到端加密。请妥善保管设备并使用可信网络。

发生涉及我们处理的个人信息的安全事件时，我们将采取相应补救措施，并按适用法律履行通知和报告义务。安全措施不能消除全部风险；本说明不排除依法应承担的责任。

## 九、账号与当前功能范围

### 当前功能范围

本版通过相机 Wi-Fi 提供实时监看、基础拍摄和机身录像控制，通过蓝牙提供无实时画面的遥控。未登录时可连接和管理相机 Wi-Fi、蓝牙及历史记录，使用基础拍照、Wi-Fi 录像和按钮对焦，查看或调整机身支持的基础曝光参数，回看和清空已保存的本机照片，并选择应用外观。

有效登录后增加普通用户的相机参数、网格、峰值、斑马纹、直方图、允许的预览与传输档位、布局和方向设置、蓝牙对焦与录像、新增拍照预览保存，以及相机照片浏览和所选原片传输。功能还受机身能力、当前状态、系统授权及连接条件限制。

本版不包含会员开通、付费订阅、申请码、兑换激活、会员查询、USB 连接或手机热点连接；不处理相应订单、支付、会员权益或兑换设备绑定信息。

### 1. 主动登录与身份验证

你主动选择华为账号登录时，应用通过华为账号服务请求基本身份及可选的头像、昵称资料，并处理身份令牌（ID Token）、请求随机校验值、应用标识、凭据签发和到期时间，以及验证后的 UnionID 和可得的 OpenID，用于确认当前用户、维护登录状态和开放普通用户功能。账号标识用于区分用户，不作为照片上传或广告跟踪标识。

应用通过 HTTPS 请求华为官方公钥，在本机验证凭据签名、应用归属、请求绑定和有效期。公钥请求不附带账号标识、身份令牌或请求随机值；服务端仍会接收到 IP 地址等必要网络连接信息。

本应用不为上述登录申请手机号、邮箱或地址，也不接收华为账号密码。华为账号服务自身为认证和安全保护处理的信息，以其授权界面及隐私声明为准。

### 2. 头像、昵称与资料授权

经你授权且通过验证的昵称和 HTTPS 头像地址用于账号页展示。你可在账号页补充授权或更新资料。未授权头像、昵称时，仍可完成基本身份登录；是否开放普通用户功能取决于有效登录状态。

显示头像时，系统图片组件请求账号服务提供的 HTTPS 头像地址，图片服务会接收到请求地址、IP 地址等必要请求信息。该请求不附带相机画面、照片、Wi-Fi 历史或配对凭据。头像不可用时显示默认头像；系统图片缓存由系统管理，退出时不能保证同步删除全部系统缓存。

### 3. 本机保存与恢复

**原始身份令牌仅在本次内存会话中保留，不写入本机登录恢复记录。**为恢复登录，应用通过 HarmonyOS 安全资产存储保存已验证的 UnionID、可得的 OpenID、应用标识、签发和到期时间、资料授权状态，以及可选的昵称和头像地址。该资产设为设备解锁时访问，并禁止该资产云同步；容量不足时可省略可选资料。

应用在启动本地服务及返回前台时核对已有记录的有效期和当前系统账号。身份尚未确认、核对失败或超时期间，只开放基础功能。有效本机记录可在离线系统账号匹配通过后恢复普通功能，沿用原有效期；离线核对不查询华为线上授权状态，也不延长凭据有效期。首次登录及过期后重新授权需要完成身份验证。

### 4. 退出、失效与华为侧授权

你选择“退出登录”，或应用发现凭据过期、系统账号不匹配、记录损坏等情况时，先撤销后续登录专属操作资格，再清理当前身份及本机登录记录。系统安全资产清理失败时会提示解锁后重试；失败不会延续原账号权限。应用停止运行期间无法在固定到期时刻执行删除，会在后续运行和读取时核对、清理。内存中的令牌随相应会话清理释放引用，不承诺所有底层内存副本即时物理擦除。

退出不会删除已保存的本机照片或完整导出原片。同一账号重新登录后，旧页面、旧目录选择器及旧任务的迟到结果不能恢复退出前的操作资格。停止已开始的录像、结束对焦、解除触控锁定、取消下载、退出页面及断开连接等必要收尾仍可使用。

本版提供本机退出，没有应用内在线撤销华为授权或注销华为账号的接口。你可通过华为账号的授权管理和账号管理渠道取消本应用授权、管理资料或注销华为账号。本机退出、本机数据清理与华为侧授权管理需要分别操作；取消华为侧授权后，也可在本应用退出并核对本机记录清理结果。
