# Z Monitor 隐私政策

- 更新日期：2026 年 11 月 12 日
- 生效日期：2026 年 11 月 12 日
- 适用应用：Z Monitor VZ1.2.0（HarmonyOS 手机版）

请在使用本应用前阅读本政策，了解我们处理哪些信息、为什么处理这些信息，以及你可以如何管理这些信息。

**本应用通过相机 Wi-Fi、USB、手机热点和蓝牙提供相机连接、监看及拍摄控制。相机画面、照片、连接历史和本机体验时间记录不会由本应用自动上传至我们运营的服务器。华为账号登录、身份验证公钥请求、头像加载、公开政策网页，以及你主动发送的反馈和个人激活申请，分别涉及相应网络服务或接收方。**

你可以不登录，使用基础连接和控制、已有本机照片回看等功能。普通用户功能和全部体验资格均要求有效登录；头像、昵称可选授权，拒绝这些资料不影响基本身份登录。**同意本政策后，应用会在本机自动建立安装时间依据、有效启动日和成功连接等资格记录；这些记录不是自动上传的使用统计。**具体处理及三种激活方式见下文。

### 1. 相机 Wi-Fi

为显示可选网络、连接你选择的相机及处理网络变化，应用使用系统返回的网络名称、网络标识（例如 BSSID）、信号、加密类型、连接状态、系统配置编号和相机地址。扫描及即时核对信息在运行中使用。

相机 Wi-Fi 密码按连接需要传给系统。应用自己的连接历史不保存密码或 BSSID；系统可能保存网络配置，由你在系统设置中管理。本机重连历史保存必要的网络名称、加密类型、配置编号、相机地址和最近连接时间，可在应用内删除。删除应用历史不自动删除系统网络配置。

### 2. 蓝牙发现、配对与遥控

应用按系统授权处理附近设备名称、信号、系统和蓝牙设备引用、相机型号、版本、能力、必要身份信息、鉴权消息和拍摄状态。首次配对需要你在系统或机身核对并确认配对码。

本机保存已完整核对相机的连接档案和最近连接快捷记录，两类各限最近 3 台。按用途包含名称、设备引用、连接类型、最近连接时间和根据本机身份与相机认证标记计算的校验摘要。原始相机识别字段、系统配对码和配对密钥不作为这些历史档案持久保存。系统蓝牙配对关系需在系统设置中另行管理。

蓝牙遥控没有实时画面。你主动切换至相机 Wi-Fi 时，应用请求相机开启 Wi-Fi、释放蓝牙，再依据系统扫描结果选网；该过程不读取相机保存的热点密码。各拍摄动作仍按登录和体验权限开放。

### 3. USB 与手机热点

你选择 USB 设备时，应用读取系统允许提供的设备及接口信息，按系统机制取得该设备的访问授权，随后与相机通信。拒绝授权时不建立该 USB 会话。设备信息用于本次识别和核验，照片或原片所含相机信息另按第三节处理。

手机热点由你通过系统设置管理。应用在本地网络发现相机，或连接你手动指定的地址，按相机提示完成配对。配对 PIN、即时相机识别资料和鉴权上下文在配对中使用，不作为热点历史长期保存，不写入应用日志。热点历史保存地址、端口和已核对状态，最多保留 20 条；不在这份历史中保存 PIN、配对 GUID 或相机序列号。随机控制端身份另行保存在本机，供必要连接使用。

### 4. 本机标识、设置和安装时间依据

应用生成并保存随机控制端身份和安装级安全标识，用于相机连接、校验记录所属安装及绑定相应资格。生成的设备私钥由本机系统安全能力保护，长期设备私钥不发送给开发者。设备公钥可进入你主动生成和发送的个人申请码。

应用保存外观、监看、传图、分组与命名偏好及说明版本。已保存的高档设置不会扩大当前权限。

**安装事件时间由系统记录。应用在首次启动且你同意适用说明后，不额外弹窗地读取并加密保存系统安装／更新时间及版本对应关系；不会用首次打开时间冒充安装时间。**相同版本核对原快照，正常升级建立新版本的对应快照。时间记录用于两个限时来源，不作为永久码激活、恢复或使用的条件。

应用同时加密保存初始化进度、原安装依据及用于核对哪些资格记录已经建立的清单。这份清单仅针对本应用的资格记录，不是手机文件目录或其他应用清单。初始化中断后，只有可靠确认此前从未完成本套限时记录的初始化，且没有普通体验领取或验收激活记录时，才沿用原安装依据继续；无法确认时拒绝相应限时资格，不清空旧记录或改成新的安装时间。验收计时使用系统开机经过时长采样，不因此增加手机硬件标识的采集。

## 三、图像、照片与后台处理

### 1. 实时预览和拍摄控制

应用接收相机预览、拍摄模式、参数和状态，用于显示、直方图、峰值、斑马纹等本机辅助分析。触屏对焦使用你的点击位置生成控制请求；延迟、间隔、连拍及长曝光处理相应参数、计时和机身返回状态。相机电量、存储卡剩余、焦距和镜头资料按能力读取。应用不利用画面识别人脸身份或建立广告画像。

实时画面随刷新替换，未主动保存的预览不作为照片档案保留。录像由相机执行并保存在机身存储卡，本版不提供视频文件下载；设置相机麦克风不等于调用手机麦克风录音。

### 2. 本机拍照预览

有效登录并启用预览保存后，应用可将拍照提交时有效的预览 JPEG 保存到私有空间，并记录文件位置、保存时间、大小、格式和尺寸。预览副本不等于相机实际曝光瞬间或原片，不会自动写入系统公共相册。

已有本机副本在未登录时也可回看、缩放、拖动和经确认整体清空。本版不提供其单张删除、导出或分享入口。单张预览上限 8 MiB，私有图片总量上限 1 GiB，索引最多 1000 条；到限停止新增，不自动删除旧照片。

### 3. 相机相册和原片下载

有效登录并满足连接方式权限后，应用通过相机 Wi-Fi、USB 或手机热点按需读取目录、文件标识、名称、格式、大小、时间、尺寸、可得拍摄参数及必要相机和存储卡身份，用于浏览、分组、JPG＋RAW 配对、命名和完整性核对。缩略图优先读取当前可见窗口，选中照片时读取较大预览；缓存按相机及文件身份核对后复用。

你主动下载时，应用接收所选 JPG、RAW／NEF 或同张照片的两种格式，校验后保存到你指定的目录。普通用户也可下载 RAW 和使用可取得的原文件名；体验资格增加分组、缩放、详细信息、快捷入队及自定义命名等操作。界面不显示某个字段，不代表原文件里没有该字段或可靠导出不需要处理它。

**原片可能包含人物影像、版权信息、拍摄时间、相机或镜头信息、设备序列号，以及机身已写入的位置等元数据。**完整原片传输保留文件已有内容，应用不会自动剥离这些字段。请在分享前检查内容，并尊重照片相关人员和权利人的权益。

应用不删除相机存储卡中的原片；原名不可取得或不适用时使用安全回退名称及重名处理，不把占位名声称为真实机身原名。

### 4. 接收目录、队列与可靠保存

系统文件选择器授予本次传图会话的临时目录访问能力，同次批量保存共用授权，退出后需重新选择。应用不保存接收目录历史或持久目录授权。导出回执和未完成清理记录仍可能包含目录及文件位置，保存位置记录不等于仍有访问授权。

可靠保存所需记录可包括来源身份、目标文件 URI、文件名、大小、校验摘要、归属和结果状态，用于重复导出保护、命名、结果核对和清理。来源身份可使用相机厂商、型号、序列号计算的摘要及照片身份；这些是可关联记录，不作为完全匿名数据。

当前下载队列不跨进程恢复。权限下降后，下一文件及新的受限操作重新核验，JPG＋RAW 中尚未开始的另一格式也算新文件。已经创建临时文件并开始接收的当前完整文件，可按原名称、目标和校验规则完成安全收尾；不能因到期中途更换保存路径。主动取消、关闭相册或断开仍按相应清理流程处理。已保存完整照片不因退出或体验到期被自动删除。

### 5. 后台与中断

后台、锁屏、来电和断连可能暂停监看、阻止新操作或中断传输；已发出的机身指令可能仍在执行，请核对相机实际状态。停止录像、结束长曝光、释放对焦、解锁、取消及断开等必要收尾保持可用。

后台或锁屏不暂停限时资格的扣时。普通 5／10 分钟体验在进程结束后不恢复；验收资格在上次运行已可靠完成保存且核验通过后，可恢复原固定截止和已确认剩余上限内的合法剩余期。强停、断电或保存失败导致上次状态无法确认时，不自动恢复，详见第九节。登录暂待核对与实际退出分开处理。

## 四、系统权限及必要性

下列系统权限按对应功能使用。拒绝或撤销相关权限可能使该功能不可用；系统授权不代替登录和体验资格核验。

| 权限 | 用途 |
| --- | --- |
| 网络访问 | 相机 Wi-Fi、手机热点通信、预览控制与照片传输，以及身份公钥、头像和主动访问网页所需网络请求 |
| 网络信息 | 识别网络状态、可用路由和连接变化 |
| Wi-Fi 信息 | 读取系统允许提供的当前网络及扫描信息，识别相机热点 |
| Wi-Fi 配置 | 按你的选网、密码和配置请求系统连接相机 Wi-Fi |
| 蓝牙访问 | 发现、配对、连接和遥控相机，并按请求切换相机 Wi-Fi |

USB 设备访问通过系统设备授权办理；原片接收目录通过文件选择器授权；华为账号和可选资料通过账号服务授权。系统应用信息、运行计时、安全存储和密钥能力按本政策所列目的在本机使用。

应用只在你点击复制申请码时写入该内容，在你主动粘贴激活码时处理粘贴文本，不后台读取剪贴板，也不自动替你发送申请。关闭输入弹窗后清理临时输入，已经成功保存的激活凭证按下文保留。

本应用不因相机控制或激活功能申请手机位置、手机摄像头、手机麦克风、通讯录或短信权限，不申请公共相册的广泛读写权限。相机照片可能自带位置信息，与你选择的文件目录授权分别处理。

## 五、信息保存、保护与清理

### 1. 保存位置和期限

本应用不设置集中保存账号、照片、连接历史、启动日或领取记录的开发者云端数据库。手机私有信息保存在本机，原片保存到你指定的目录。**你主动向开发者发送的永久激活申请和反馈由开发者接收并处理，不能因为兑换验证离线就理解为这些主动发送的信息仍只存在手机。**第三方网络服务、系统备份及云盘按其各自场景处理信息。

| 信息 | 保留及清理规则 |
| --- | --- |
| 预览、扫描、USB 枚举及配对临时数据 | 相应会话使用，随刷新、操作结束、取消、断开或进程结束释放引用；不建立设备扫描轨迹档案 |
| Wi-Fi、蓝牙、热点历史 | Wi-Fi 历史保留至删除或清理应用数据；蓝牙两类历史各最多 3 台，热点历史最多 20 条，可删除或随数量限制替换；系统网络配置和配对另行清理 |
| 控制端标识、功能偏好、说明版本 | 在本机保留至相关设置变更或应用私有数据清理；系统备份恢复可能影响实际保留情况 |
| 私有预览副本和索引 | 保留至整体清空或清理应用数据，达到容量上限停止新增，不自动删除旧图 |
| 相册目录、缩略图、较大预览 | 主要在内存处理；退出详情可清除详情显示，同一相机目录和缩略图可在本次运行复用，切换相机或进程结束释放对应缓存 |
| 传输临时文件和清理记录 | 完成、取消或关闭会话时安排清理；目标位置需核对归属和访问条件，失败时保留必要重试记录 |
| 导出回执、命名与来源对应 | 成功回执最多 1000 条，未完成清理记录最多 128 条，来源对应最多 2000 条，并受状态容量限制；成功回执和来源对应按数量与容量裁剪，未完成清理记录仅在处理完成后移除，到限暂停新增，不按数量丢弃旧待清理项；清理应用数据也会影响这些记录，删除记录不删除完整原片 |
