# Z Monitor 隐私政策

- 更新日期：2026 年 11 月 2 日
- 生效日期：随 Z Monitor VZ1.0 正式发布之日起生效
- 适用应用：Z Monitor（HarmonyOS 手机版）

请在使用本应用前阅读本政策，了解我们处理哪些信息、为什么处理这些信息，以及你可以如何管理这些信息。

**当前 VZ1.0 主要通过手机与相机之间的本地连接提供实时预览、拍照控制和拍照辅助功能。相机预览画面、连接信息和本地图片不会由本应用自动上传至我们运营的服务器。本应用无需注册账号，当前未接入广告、第三方行为统计或云端相册服务。**

本政策同时说明计划扩展的手机热点连接、相机文件下载到本机功能。**这些计划功能在当前 VZ1.0 中尚未开放。相关说明不表示本应用现在已提供这些功能，也不构成你对未来新增信息处理或设备权限的预先授权。**

## 一、运营者及适用范围

**运营者：胡绍阳**

Z Monitor 是由胡绍阳（以下简称“我们”）提供的手机相机监控与控制应用。本政策说明运营者提供手机应用时的信息处理活动，以及本隐私政策网页的访问说明。有关隐私问题，你可以通过第十一节列明的邮箱联系我们。

本政策适用于 Z Monitor 手机应用。你通过应用访问外部网站、使用邮件服务，或使用系统提供的网络、相册、文件管理和云备份服务时，相应服务提供者也会按照其自身的规则处理信息。

我们仅在取得你的同意、提供你主动请求的服务所必需，或履行法定义务等合法基础上处理相关信息。

## 二、我们处理的信息及用途

我们按照功能需要处理下列信息。实际可获得的字段取决于手机系统和相机返回的内容。

| 信息类别 | 具体内容 | 用途及处理方式 |
| --- | --- | --- |
| 网络与 Wi-Fi 连接信息 | 网络连接状态、Wi-Fi 热点名称、加密类型、系统网络配置编号及相机局域网 IP 地址 | 用于发现、连接你选择的相机，以及恢复连接；用于重连的历史信息保存在本机应用私有空间 |
| 蓝牙连接与配对信息 | 蓝牙设备名称、系统设备引用、连接方式、配对或连接记录、最近连接时间及本地校验信息 | 用于发现、识别、连接你选择的相机和蓝牙遥控；必要的连接记录在本机保存 |
| 相机设备与状态信息 | 相机型号、相机返回的设备信息与能力、拍摄状态、曝光参数等，可能包含相机序列号 | 用于当前连接和相机适配，在手机本地处理，不作为广告标识使用 |
| 本机生成的连接标识 | 本应用生成的控制端身份或连接标识 | 用于相机识别与连接，不来源于手机硬件序列号；为后续连接在本机保存 |
| 实时预览与已保存图片 | 相机预览画面、用户主动保存或拍照时保存的预览 JPEG 图片 | 用于实时显示、拍照辅助分析和用户请求的本地保存，具体见第三节 |
| 应用设置与图片索引 | 拍照辅助设置、连接偏好；图片的本地编号、保存时间、尺寸、格式和文件大小 | 用于保存使用偏好和管理本地图片，在本机保存 |
| 隐私选择记录 | 你同意的隐私政策版本等记录 | 在本机保存，用于记录你的选择并判断是否需要再次提示 |
| 必要的运行诊断信息 | 运行期间有限的连接与控制诊断信息 | 在运行内存中用于故障排查，不自动发送给我们或第三方统计平台 |
| 你主动提交的反馈信息 | 发送邮件时提供的邮箱地址、问题描述及自行附带的图片、日志或其他文件 | 用于回复和排查你反馈的问题；反馈材料的保存与清理见第五节 |

连接历史中用于重连的信息保存在本机应用私有空间。Wi-Fi 密码在建立连接时按照系统接口要求传递，当前版本不会将其写入应用自己的 Wi-Fi 历史记录；系统可能根据你的操作保存网络配置。

如果你主动通过邮箱反馈问题，我们会处理你发送的邮箱地址、问题描述及你自行附带的图片、日志或其他文件，用于回复和排查你反馈的问题。请仅提供排查所需的信息，并在发送前移除无关的人像、位置、设备凭据及其他敏感内容。我们不会要求你提供相机连接密码、手机解锁密码或账号密码。

## 三、图像、照片与后台处理

1. 相机发送的预览画面在手机本地用于实时显示，以及直方图、峰值对焦提示、斑马纹等拍照辅助分析。本应用不使用这些画面进行人脸身份识别或广告画像分析。

2. 实时预览主要在内存中处理，画面会随预览刷新而替换。你主动执行保存操作，或使用带有预览保存行为的拍照功能时，应用会保存当时有效的预览 JPEG 图片。

3. **当前版本在手机保存的是相机预览画面，不是从相机存储卡下载的原始照片。图片存放在应用私有空间，不会自动写入系统公共相册。** 录像按钮用于向相机发送开始或停止录像指令，当前版本不因此将相机视频下载到手机。

4. 画面可能包含人物等个人信息。图片中也可能保留相机附带的拍摄信息或其他元数据；本应用不承诺自动清除这些信息。请在向他人提供图片前检查其内容及附带信息。

5. 切换至后台、锁屏或发生其他可观察到的交互中断时，应用根据当前状态暂停监看和拍摄计划。已经发送给相机的操作可能仍由相机继续完成，离开应用不能保证停止相机录像，请以相机实际状态为准。

## 四、系统权限及必要性

为实现相机监看、控制和连接状态展示，本应用使用以下系统权限：

| 权限 | 用途 |
| --- | --- |
| 网络访问 | 在手机和相机之间传输预览画面及控制指令；用于网络连接相机；具有联网权限不表示应用会上传相机内容至云端 |
| 获取网络状态 | 判断网络是否可用以及连接状态；用于连接提示和故障判断 |
| 获取 Wi-Fi 信息 | 识别当前网络及相机热点相关信息；在使用 Wi-Fi 相机连接功能时使用 |
| Wi-Fi 连接与配置 | 连接你选择的相机热点；按照系统提供的接口和交互执行 |
| 蓝牙访问 | 发现、连接相机并进行蓝牙遥控；在你使用蓝牙功能时依照系统要求申请；拒绝后无法使用相应蓝牙功能，仍可使用符合条件的 Wi-Fi 功能 |

当前版本不申请手机摄像头、麦克风、位置及公共相册读写权限。相机文件自身可能包含的位置、人物或声音等内容，与应用是否申请手机位置、摄像头或麦克风权限属于不同的信息来源。

你可以通过手机系统设置管理授权。不同系统版本的权限名称、提示及操作入口可能存在差异。

## 五、信息保存、保护与清理

### 1. 保存位置和期限

当前版本的应用设置、连接历史、同意记录和已保存预览图片存储在你所使用的手机本地应用私有空间。我们未为当前版本设置用于接收相机画面、相机文件或连接信息的开发者服务器，也不会由本应用主动将这些数据传输至境外。

- **实时预览与会话状态：** 在相关功能运行时临时处理，随画面更新、连接结束或进程结束被替换或释放；你主动保存的图片除外
- **运行期间的内存诊断信息：** 在运行期间有限保存，随记录替换或进程结束清除，不作为自动上传的持久日志
- **应用内保存的预览图片：** 保留至你在应用中删除，或通过系统清除应用数据、卸载应用；系统备份或恢复可能影响实际保留情况
- **连接历史：** Wi-Fi 历史保留至你删除相应记录，或通过系统清除应用数据、卸载应用；蓝牙仅保留最近最多 3 台相机记录，较旧记录可能被新记录替换，你也可主动删除
- **应用设置、同意记录及本机生成的连接身份：** 在本机保留以支持后续使用，可通过系统清除应用数据或卸载应用清理
- **你主动提交的反馈信息：** 保留至反馈处理完成；处理完成后删除不再必要的信息。依法必须保留或存在尚未解决的争议时，仅在相应义务或争议处理所必要的期限内保留

法律法规另有要求时，按照相应要求处理。我们仅在实现处理目的所必要的范围和期限内保存信息。

系统自身保存的 Wi-Fi 配置、蓝牙配对，以及你主动导出至相册或其他目录的文件，由相应系统功能管理，可能需要你单独删除。你自行开启的系统备份、相册云同步或其他第三方同步服务可能对文件进行备份或传输，这些服务按照其自身规则运行。

### 2. 保护措施

我们采取与信息处理风险相适应的措施，包括限制功能所需权限、使用应用私有存储、控制本地诊断记录范围，以及避免在诊断中记录连接密码等。

相机支持的通信协议和安全能力可能存在限制，部分预览或控制通信未提供应用层端到端加密。建议你使用可信的个人网络和相机连接环境，并妥善保护热点密码、手机及相机。

如发生或可能发生个人信息泄露、篡改、丢失等安全事件，我们将依法采取补救措施，并履行适用的告知、报告义务。

## 六、第三方服务、分享及网页访问

我们不会出售你的个人信息，也不会将你的相机画面或文件用于广告投放。当前版本未接入第三方广告、行为统计或开发者云端图片存储 SDK。

为完成你主动请求的功能，本应用会调用手机系统提供的网络、Wi-Fi、蓝牙、应用私有存储等接口，并向你选择连接的相机发送必要的连接信息和控制指令。后续提供文件保存或分享功能时，相应数据仅按照你的操作交给你选择的系统功能或目标应用。

如未来新增受托处理方、第三方 SDK 或向其他个人信息处理者提供信息的情形，我们会在相关处理发生前说明接收方、处理目的、信息范围及必要的授权安排。依法向有权机关提供信息时，我们将按法律要求处理，并控制在必要范围内。

### 隐私政策网页的访问

本政策的公开页面使用 GitHub 托管。你通过 GitHub 或 GitHub Pages 浏览该页面时，GitHub 可能处理访问日志、IP 地址、浏览器信息等网站访问数据，其处理和存储规则请参阅 [GitHub 隐私声明](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)。页面托管不用于接收本应用的相机图片、相机文件或连接凭据。

### 主动联系与反馈

你主动发送反馈邮件时，邮件服务提供者会按照其规则处理邮件传输及存储。请勿在公开的 GitHub Issue、评论或其他公开页面提交包含个人信息的图片、日志、密码或设备凭据。

## 七、你的选择与个人信息权利

### 阅读、同意和拒绝

首次使用时，应用会展示隐私提示，提供本政策的查阅入口，并由你明确点击同意或拒绝。**在你同意前，本应用不会开始相机发现、无线扫描或连接相机。** 你可以拒绝同意并退出应用。

已同意后，你可以通过 **隐私与协议 → 隐私政策与个人信息处理范围** 重新查看本政策。仅重新阅读不会撤回已保存的同意。

同意本政策不等于授予全部系统权限。需要系统授权的功能会在你主动使用相关功能时，依照系统机制申请必要权限。拒绝某项可选权限会影响对应功能，不会因此扩大其他信息的处理范围。

### 停止使用、撤回与删除本地数据

如需撤回对应用信息处理的整体同意，可停止使用，并通过系统“清除应用数据”或卸载应用清除本机同意记录及应用私有数据。再次使用时需要重新作出选择。操作前请注意，应用私有空间内保存的图片也可能一并删除。当前版本未提供应用内单独的撤回开关。

- 在“本地照片”页面查看和删除已保存的预览图片。删除这些本地图片不会删除相机存储卡中的原始文件。
- 在应用的相应连接历史列表中删除 Wi-Fi 或蓝牙连接记录。删除应用记录不会自动删除系统保存的 Wi-Fi 配置或解除系统蓝牙配对。
- 在手机系统设置中管理本应用的设备权限。撤销蓝牙等权限后，对应功能将无法继续使用。

### 查阅、更正及联系请求

对于应用内无法完成的查阅、复制、更正、补充、删除、限制处理、撤回同意或其他个人信息权利请求，可通过本政策列明的邮箱联系我们。

撤回同意不影响撤回前基于你的同意已经进行的信息处理的效力。对于由你保存在本机且未发送给我们的数据，我们无法远程读取或代为删除，可向你提供相应的本地操作指引。我们仅在处理请求确有必要时核验你的身份，不要求提供与请求无关的信息。

## 八、未成年人保护

未满十八周岁的用户应在监护人指导下阅读本政策并使用本应用。本应用不以不满十四周岁的未成年人为目标用户，也不会主动要求提供儿童姓名、身份证件或其他身份资料。

如确需基于同意处理不满十四周岁未成年人的个人信息，我们将依法取得监护人同意并采取相应保护措施。监护人如认为相关信息处理存在问题，可通过下述邮箱联系我们。请勿通过反馈渠道发送与问题排查无关的未成年人影像或身份信息。

## 九、账号与当前功能范围

当前版本无需注册账号，未接入广告、第三方行为统计或云端相册服务。

以下功能尚未在当前 VZ1.0 中开放。我们将在对应功能发布前，更新本政策并在功能入口明确说明实际处理的信息、权限、保存位置、保存期限和管理方式。依法需要重新取得同意或申请系统授权时，将在你使用前取得相应同意或授权。

### 1. 手机热点连接相机

计划支持由手机提供热点、相机接入该热点后进行本地通信的连接方式。仅在你主动选择该方式时，才会执行对应的连接操作。

该功能预计需要在本机处理热点或局域网连接状态、相机网络地址、设备连接标识等信息。如果具体实现需要你提供或通过系统授权获取热点名称、密码等配置，我们会在操作前说明所需信息及用途，仅将其用于你选择的相机连接。

手机热点的开启、管理或配置读取将遵循系统支持的能力和授权流程。如果需要保存连接配置，我们会在保存前说明保存内容、用途和期限，并提供相应的管理方式。当前版本不会因为你同意本政策就提前读取这些计划功能所需的信息。

### 2. 相机文件下载到手机本地

计划支持由你主动浏览和选择相机中的文件，并将所选文件传输到手机本地。具体支持的相机、文件格式和传输能力，以届时发布版本为准；相关格式可能包括 JPEG、RAW／NEF 照片及视频，不代表所有相机和格式均会受到支持。

为展示文件列表、缩略图、匹配文件及完成下载，应用可能需要从相机读取文件编号、文件名、文件类型、大小、拍摄时间、缩略图及你选择下载的文件内容。批量传输也应由你主动选择和启动，不会仅因你同意隐私政策而自动下载整张存储卡。

**原始照片和视频可能包含人物、声音，以及拍摄时间、相机型号、镜头、曝光参数、版权、相机序列号或嵌入的位置信息。原样传输可能保留这些内容及元数据；本应用不会将“不申请手机位置权限”解释为文件中不含位置数据。**

文件将从你选择的相机传输到手机本地，用于你请求的预览、保存和管理，不上传至我们运营的服务器。下载中断时所产生的临时文件或进度记录，其保存和清理规则会在功能上线时明确说明。

如果后续提供保存至系统相册、导出至你选择的目录或分享文件的功能，我们会在你主动执行相应操作时，通过系统提供的保存、文件选择或分享机制取得必要授权或文件访问权限。应用私有目录、系统相册及你自行选择目录中的文件，其删除和卸载后的保留情况不同，届时会明确提示。

## 十、政策更新

我们会根据功能变化和法律要求更新本政策，并通过应用内提示、政策页面等适当方式说明重要变化。

涉及处理目的、处理方式或信息种类变化，以及新增需要另行取得同意的处理活动时，我们将在相关处理开始前重新告知并依法取得相应同意；不会仅以“继续使用”代替依法需要的明确同意。

手机热点连接、相机文件下载等计划功能实际上线前，将核对并更新相应说明。届时的功能启用提示、权限申请和隐私政策应与实际实现保持一致。
